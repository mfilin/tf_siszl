# Учёт файлов ДН · GST / GPT / GF

React + TypeScript прототип трёх экранов на shadcn/ui: журнал обмена, содержимое GF и сводка результатов сверки. Данные в интерфейсе демонстрационные; API-контракт см. в [../docs/REST_API.md](../docs/REST_API.md).

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Компоненты shadcn/ui находятся в `src/components/ui`; стили темы — в `src/index.css`. В `App.tsx` оставлены локальные демонстрационные данные и логика фильтров, экспорта, карточек и аналитики. Для подключения сервера замените эти данные вызовами REST API из документации.
